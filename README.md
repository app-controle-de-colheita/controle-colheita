# morango-colheita

App de controle de colheita de morango, com dashboards interativos por lavoura e safra.

## Estrutura

- `backend/` — API FastAPI + SQLite (roda no Raspberry Pi)
- `frontend/` — HTML/CSS/JS estático (hospedado no GitHub Pages)

## Stack

- **Backend:** Python + FastAPI + SQLite + JWT
- **Frontend:** HTML/CSS/JS puro + Chart.js
- **Hospedagem:** Frontend no GitHub Pages, backend no Raspberry Pi via Tailscale Funnel
